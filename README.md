# notebookTools

Zweites BfK-S Projekt

## Ziel

Dieses Projekt ist ein C#-Kommandozeilentool zum Lesen und Bearbeiten von Jupyter Notebook Dateien im `.ipynb`-Format.

## Geplante Funktionen

- Notebook einlesen
- Inhaltsübersicht anzeigen
- einzelne Zellen anzeigen
- Zellen löschen
- neue Zellen einfügen
- Notebooks zusammenführen
- Unit Tests für wichtige Funktionen

## Projektstruktur

- `src/NotebookTools`: Hauptprogramm
- `tests/NotebookTools.Tests`: Unit Tests
- `docs`: Analyse und Projektdokumentation
